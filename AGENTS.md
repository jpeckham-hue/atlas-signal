# Atlas Signal Agent Entry Point

## Project state first

**Before planning, coding, reviewing, or reporting project status, read `PROJECT_STATE.md`. Then read `CLAUDE.md` for the repository's existing contributor rules.**

`PROJECT_STATE.md` is a navigation index, not experimental authority. Follow its explicit source paths and verify relevant files/commits before making status claims. In particular, distinguish frozen experiment specifications from later implementation progress and distinguish pushed GitHub state from local/uncommitted Codex work.

When a canonical roadmap/current-state source, branch responsibility, major priority, blocker, or significant milestone changes, update `PROJECT_STATE.md` in the same change set.

If `PROJECT_STATE.md` is missing, stale, or contradicts its linked source documents, flag the problem immediately and verify source truth before continuing.

## Preserve existing research governance

Do not replace or weaken `CLAUDE.md`, frozen experiment designs, anti-leakage rules, sealed artifacts, research manifests, or test/evidence boundaries. This file only establishes the project-state retrieval entry point.
